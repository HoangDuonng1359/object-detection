YOLOv8-Style Hybrid: ResNet Backbone + PAN-FPN + DFL Head

Kiến trúc hiện tại đã bỏ P2 stride 4 để giảm VRAM và tăng tốc. Model còn 3 scale dự đoán: stride 8, 16, 32.

1. Sơ Đồ Tổng Quan

2. Feature Pyramid Sau Khi Bỏ P2

P2 stride 4 đã được gỡ để giảm bộ nhớ. Với input 512, model không còn tạo feature map 128 x 128 nữa. Scale nhỏ nhất hiện là stride 8, tức 64 x 64.

Scale Stride Feature size khi input 512 Vai trò
P3 8 64 x 64 Object nhỏ đến vừa.
P4 16 32 x 32 Object vừa đến lớn.
P5 32 16 x 16 Object lớn, ngữ nghĩa mạnh.

3. Head Dự Đoán Gì?

Box tower Dự đoán DFL distributions cho left, top, right, bottom.
Objectness Dự đoán xác suất cell có object.
Class tower Dự đoán logits cho person, car, dog, cat, chair.
Confidence max sigmoid(class_logit). 
Output for IMAGE_SIZE = 512:
[
  B x 73 x 64 x 64,  # stride 8
  B x 73 x 32 x 32,  # stride 16
  B x 73 x 16 x 16,  # stride 32
]

4. Box Decoding

distance = expectation(softmax(distribution_bins)) * stride
point_x  = (grid_x + 0.5) * stride
point_y  = (grid_y + 0.5) * stride

bbox = [
  point_x - left,
  point_y - top,
  point_x + right,
  point_y + bottom,
]

5. Loss Khi Train

Thành phần Phương pháp Trọng số
Box loss 1 - CIoU 5.0
DFL loss Distribution focal loss for l/t/r/b 1.0
Objectness loss Focal BCE with logits 1.0
Class loss Cross entropy 0.5
Sau khi bỏ P2, object nhỏ nhất được gán về stride 8 thay vì stride 4. Điều này nhẹ hơn đáng kể, nhưng có thể làm recall của object rất nhỏ giảm một chút.

6. Predict Và NMS

image
  -> letterbox resize
  -> normalize
  -> model forward
  -> decode boxes
  -> class threshold
  -> NMS riêng từng class
  -> scale bbox về ảnh gốc
  -> predictions.json
python predict.py \
  --image_dir public/val/images \
  --output predictions.json \
  --checkpoint models/best.pth \
  --conf_threshold 0.25 \
  --class_thresholds "person=0.25,car=0.20,dog=0.25,cat=0.25,chair=0.10" \
  --nms_threshold 0.35
Hạ threshold tăng recall nhưng cũng có thể tăng false positive. Nên chọn threshold bằng validation sweep.

7. Tóm Tắt

Backbone ResNet50/ResNet101 pretrained backbone.
Neck YOLOv8-style PAN-FPN, 3 scale, 256 channels.
Head Anchor-free decoupled head.
Strides 8, 16, 32.
Output channels 73 per scale = 4 * 17 DFL bins + 5 quality-aware class logits.
Lợi ích sau khi bỏ P2 Ít tốn VRAM hơn, train ổn định hơn, predict nhanh hơn.
Đánh đổi Object rất nhỏ có thể khó bắt hơn so với bản có stride 4.
